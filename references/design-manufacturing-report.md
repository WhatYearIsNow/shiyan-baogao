# 设计制造与观察类实验报告

设计与制造基础、材料显微观察、工艺制备、热处理、焊接组织等实验时读取。核心不是套用固定目录，而是逐项满足本次指导书的报告要求。

## 1. 先还原本次实际实验

先定位该实验自己的“实验报告要求”，同时读取本次逐字稿、现场照片、本人观察和用户确认，不要只读实验目的或相邻实验。把每条要求拆成对象、动作、数量、图幅、标注字段和结论任务，再核对本次实际上课与操作是否有变更。

本次证据明确时，逐字稿、现场照片和本人观察优先说明实际试样、操作与结果；指导书提供默认要求和规范。二者不一致时记录“默认项—本次变更—证据”，按教师本次明确安排或用户确认执行；若照片身份或口述含义不唯一，不能自行裁决，须先确认。

已有报告只作实战样板：若样板扩写了许多章节，删除与本次有效要求无关的内容；若它更换了试样、牌号、处理状态、图数或字段，不能因为“往届这样写”就沿用，也不能反过来仅凭指导书否定本次现场证据。

## 2. 输入与来源分层

| 内容 | 可写语气 | 必要核验 |
|---|---|---|
| 本人现场观察/本人照片 | “观察到……” | 对象、倍率、处理状态、照片与试样对应关系 |
| 用户依据照片确认的草图 | “根据本次观察绘制……” | 特征与照片一致，未凭空补组织 |
| 教师课件或黑板示意 | “参照图显示/用于识别……” | 不冒充本人观察；若明确说明本次对象变更，登记为课堂要求 |
| 教材典型组织 | “理论上/典型特征为……” | 材料牌号、成分和处理状态适用 |
| 历史报告图 | 仅作版式或字段检查 | 不复制成此次结果 |

照片不清时可结合教师课件识别候选特征，但最终“观察到”的内容须由用户确认。无法确认的组织、相比例、缺陷或处理状态保持待核，不用理论图填空。

## 3. 写作结构

### 必写内容

按要求矩阵原顺序组织。通常包括实验名称和目的、规定操作规程/制备过程、规定观察图或结果表、要求的组织/性能分析。只有指导书或教师要求时才加入完整原理、设备清单、独立结论、思考题。

### 操作与制备

摘要描述而非照抄指导书。保留顺序、关键控制量、判据、安全或会影响结果的动作，例如逐级磨制、换向、抛光供液、浸蚀终点和清洗干燥。课堂口述中的本次特殊操作可补充，但 ASR 含糊词需核对。

### 观察图和图注

- 先满足规定图幅和数量；若要求固定直径的圆形视场，输出中实际核对尺寸。
- 每幅图的材料/牌号、组织或区域、处理状态、浸蚀剂、放大倍数及指导书另列字段逐项填写。
- 线条、明暗、相区和晶界只表现本次可确认特征；必要时使用图例或箭头。
- 实拍照片可作附加证据，但要求绘制示意图时不能只贴照片。教师课件图若允许引用，图注标明参照性质。

### 分析与结论

从“观察特征—材料/工艺条件—机理—要求回答的关系”组织。不要写脱离图片的材料学百科；没有实测面积分数时，不把目测“大致相符”升级为定量验证。工艺缺陷或操作影响只有在本次观察或对照支持时写成事实，否则写为可能影响与验证方法。

## 4. 凝练门槛

删除：与要求无关且未解释本次结果的整段理论；重复目的、步骤、结论的同义句；没有本次观察的通用误差清单；自行添加且无课程依据的思考题；仅为显得完整而加入的设备百科或“达到了实验目的”。

保留：本次要求、关键操作判据、规定图示与字段、观察和理论的必要对照、能够回答要求的结论。

## 5. 验收重点

- 要求矩阵中的对象、数量、图幅和字段全部闭合，指导书默认项与本次现场变更均可追溯。
- 本人观察、教师示意、教材典型图和历史样板未混淆。
- 规定绘图没有被实拍照片替代，实拍照片也没有被未经说明的生成图冒充。
- 分析真正解释本次图或结果，删去了无结论的长段。
- 报告名称、图注对象、材料牌号和处理状态相互一致。
