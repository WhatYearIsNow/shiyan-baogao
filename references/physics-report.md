# 物理实验报告

物理实验的数据处理、完整报告、局部章节或交前审查时读取；数学细节同时读取[计算契约](calculation-contract.md)。

## 1. 可选范围

| 模式 | 适用请求 | 正文范围 |
|---|---|---|
| 数据/后半部分 | 用户已写预习报告或只要计算、图表、讨论 | 不重复目的、仪器、原理与步骤 |
| 精简完整 | 默认完整报告 | 精炼前置内容 + 数据处理 + 讨论/结论 |
| 全面完整 | 用户明确要求更全面 | 增加必要推导、设备规格、完整步骤或思考题 |

用户没有给前置材料但要求完整报告时，先检查指导书、教材、报告纸和可用往届结构；缺少决定性课程要求时确认，而不是凭常见模板补齐。

## 2. 前置内容的来源与压缩

- **实验目的**：以指导书或本次教材为主，合并同义项；每项对应待测量、待验证关系或待掌握方法。
- **仪器**：列出影响计算、误差或操作的仪器和关键规格。与结果无关的完整设备百科通常不写。
- **原理**：保留本次实际使用的关系式、符号定义、适用条件和必要示意；不抄整章教材。正文公式必须与复算驱动一致。
- **步骤**：写会改变测量条件、数据有效性或不确定度的动作；通用开关机流程只有在指导书要求时保留。
- **往届报告**：用于发现结构、教师批注与讨论深度基准，按“年份越晚、得分越高越优先”取用；不复制目的、步骤、数字或误差原因，当前教材和课堂口径优先。

精简时优先删除重复定义、未进入计算的推导和不影响结果的操作细节，不能删报告纸明确要求、关键控制条件或安全事项。

## 3. 数据与计算

保持原始记录、选用集合、派生量和展示值四层分离。原始数据异常时先按证据判断；补测只替换被确认失效的具体数据，除非用户或课程明确要求整组重测。不得为减小误差挑数据。

每类结果至少保留原形公式、一次代表性代入、带单位结果、不确定度或百分差定义、修约依据。重复性、参考偏差和总不确定度不可互相替代。

## 4. 结果讨论与结论

读取[结果讨论与分析](analysis-discussion.md)。先再次确认实验结论，再分析本次最有解释力的趋势、异常、模型边界和装置观察。每个原因说明进入公式或物理过程的路径；没有对照时写为可能原因。

结论回答实验目的，不重复整张数据表。思考与改进可以从实验特点推导，但若不是教师原题，必须以陈述语气标为“思考与改进”，不能冒充课程题目。

## 5. 验收重点

- 所有原始读数、公式、常数、单位和表格显示逐项回看，不只抽查“看起来合理”。
- 图中数据点与表格同源；拟合与理论线分开标注，相关系数不单独证明理论。
- 质量、尺寸、校准量等关键输入来源真实；参考或反算值不写成实测值。
- 报告正文与后附说明口径一致；说明中的数据替换或限制若改变结论，正文保留必要边界。
