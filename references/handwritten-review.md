# 誊抄后独立复核

当用户提供已誊抄、重算或自主调整的手写报告、扫描 PDF 或照片，要求检查错误、判断能否提交时读取。生成期自身校验照常执行；本模式另以用户完成的报告为审查对象，仅在收到复核请求时启动。也适用于用户在生成稿上修改后的电子报告。

## 跨会话接续

先确定本次实验、日期、提交版本与页序。按课程卡、文件路径和现有处理记录查找：用户报告、此前 skill 产物、原始记录/观察、复算驱动，以及本次逐字稿和现场材料。优先使用用户指定版本，不能只凭文件名“定稿”或修改时间推定。

无需依赖旧聊天记忆，也不要求重新生成报告。已有文件可直接读取；缺少对照稿时仍可检查内部一致性和可核实的事实，只对来源比较保留边界。相同实验存在自测、往届或他人数据时须区分身份，不能混作本次输入。只询问影响判断且无法从本地材料解决的缺项。

## 以事实为主逐页核查

查看实际页面，按需放大公式、数字与图注；OCR 只能辅助定位。读不清的负号、指数、单位、材料名或数值先回看，仍不唯一则定位询问，不能先判为誊抄错误。按请求核对以下内容：

- 数据、符号、正负号、指数、单位、有效数字、表头量纲及公式系数；检查直径/半径、单次周期/累计时间、实验值/理论值等含义。
- 代入、计算与图表数值是否一致，结论是否由本次结果支持；质量、尺寸、标定量或数据集合变化时，追查受影响的表、拟合和讨论。
- 实验对象、材料/组织、处理状态、方法、装置和观察叙述是否符合本次原始记录与课堂证据；保留指导书默认要求与本次明确变更的区别。
- 图示标注、规定项目和关键结果是否缺失，图与正文是否相符。身份、日期、页序及附件只作必要完整性检查；语言润色和美观建议低于事实错误。

若无相关计算，只核查适用项目，不为定性观察实验补不确定度或凑数字检查。

## 发现差异后诊断

原 skill 产物是对照材料，也可能有错，不能因手写件与它不同就判错。将差异归为：

| 判断 | 依据与处理 |
|---|---|
| 确认错误 | 原始记录、复算或明确课程事实能证明；给最小修正和影响范围 |
| 合理改动 | 用户的推导、修约、表达或结论仍成立，或纠正了原产物；明确可以保留 |
| 待确认 | 读不清、来源缺失、版本或本次工况不明；写清无法判断之处并实际提问 |
| 仅表达差异 | 语义、数值与结论等价；不列为必须修改项 |

对实质改动，按“改了什么 → 有无依据 → 如何影响下游 → 是否需要修改”说明；必要时用原始输入复算。可以推测原因，但要区分可见事实与诊断假设，不把“误抄”“误解公式”当作已证实动机。发现生成稿错误时明确指出并修正判断，不要求用户改回错误旧稿。用户新增的观察或依据无法验证时先确认，不能只因原稿没有就否定。

## 输出与完成状态

先回答是否存在需要修改的明显事实错误；按影响从高到低列问题，给出实际页码与表/行/公式位置、当前写法、证据、影响及建议修正。无问题时简洁说明实际核查范围。合理改动可集中写一小段；少量不影响事实的表述建议最后列出，不整篇重写。

例如：`第2页表3第二行：当前数值……；原始记录/复算……；影响……；建议改为……。` 无明确依据时不补一个“更合理”的数。

未核对到的页、缺失原始资料及仍不可辨认的关键位置，明确限制哪些结论。只有当前可见范围内没有明显错误时才作对应判断；不以与原产物一致或 PDF 清晰代替事实正确，也不承诺教师评分。复核结果与用户原件分别保留，记录所审版本、依据和未决项；默认给出修正建议，不覆盖用户手写件、不自动提交。
