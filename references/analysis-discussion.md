# 结果讨论与分析

用户要求完整的结果分析、误差讨论、实验结论、思考或改进时读取。只需要计算结果或 2–4 条分析素材时，不必强行扩写成完整章节。

## 1. 目标与边界

结果讨论不是重复计算过程，也不是通用误差清单。它要用本次实验的证据回答四个问题：

1. 实验实际得到什么结果，支持什么结论；
2. 数据呈现什么趋势、差异或异常；
3. 哪些因素可能解释主要偏差，证据有多强；
4. 怎样复测或改进，才能区分原因或减小影响。

报告正文只写本次结果、观察及其机理解释。读数校订、异常值替换、参数来源、照片身份、条件计算、历史报告对照和识别过程属于处理说明或溯源记录；它们若实质限制结论，正文以简短边界表达，例如“在所采用的标定条件下”或“据本次显微观察”，不展开数据修订经过。

处理说明尽量不省略内容：用户与 AI 讨论的误差、实验现场情况、用户自己的思考与疑问，都应写进处理说明作为可追溯佐证，不设篇幅上限。其中**有本次证据支撑、体现思考深度**的讨论点（如异常数据的定量归因、装置缺陷与结果偏差的联系）可升入正文讨论节，但升入后仍须满足正文门禁：只用本次数字或明确观察，机理解释与原因假设分开，不把假设写成已查明事实。

往届报告可用于识别常见结构、教师批注和实验特有问题，但不是事实来源。当前实验表、课件、逐字稿和用户确认优先；往届数字、结论和误差原因不得直接移入本次正文。正文也不主动提及“往届报告”。

## 2. 先建证据清单

写作前从复算结果、图表、原始记录和已确认观察中提取以下内容。没有证据的格子可以为空，不能用套话补齐。

| 证据类 | 要找什么 | 典型表达 |
|---|---|---|
| 核心结果 | 最终值、不确定度、相对偏差或关键比较 | “测得……；与参考值相差……” |
| 关系与趋势 | 单调性、线性、峰值、平台、斜率、截距、残差 | “在……范围内随……增加而……” |
| 重复性 | 极差、标准差、重复读数分布 | “重复测量波动为……，表明……” |
| 异常 | 与其余点不同的方向、量级和位置 | “仅……组明显偏高/偏低……” |
| 条件与现象 | 已确认的安装、环境、操作或样品特征 | “实验中观察到……” |
| 模型边界 | 理想化假设、标定共享、数据路径是否独立 | “该比较共用……，不能作为独立验证” |

数值只保留到支撑判断所需的精度。核心结论至少绑定一个本次定量结果或明确观察；不要求每句话都堆数字。相对偏差、标准不确定度和重复性是不同概念，不能互相替代。

## 3. 先判定实验类型

同一实验可能兼有多类，以主要任务决定正文重心。

| 类型 | 必写重点 | 常见误区 |
|---|---|---|
| 定值测量型 | 最终值与不确定度、参考比较、主导分量 | 只报百分差，不说明测量质量 |
| 规律验证型 | 关系是否成立、适用范围、偏离点 | 只凭相关系数接近 1 宣称理论正确 |
| 趋势/拟合型 | 趋势、参数、残差或异常点、模型边界 | 把平滑曲线当作因果证明 |
| 比较/标定型 | 方法间差异、独立性、标定传递 | 用同一标定量循环“互证” |
| 定性观察型 | 观察到的现象、发生条件、机理解释 | 无实际观察却照抄教材现象 |

只有在比较路径彼此独立时，才使用“相互验证”。由同一组数据反算的参数再回代得到吻合，只能说明内部一致，不能作为独立证据。

## 4. 自适应选模块

默认正文采用 3–5 个短段或条目，不把所有模块机械写全。

### 必选 A：结果与结论

- 先给最重要的结果，再说明它支持、部分支持或不支持什么结论。
- 同时交代适用范围和主要例外。结果混合时不能用一句“实验成功”抹平异常。
- 验证性语言按证据强度选择：“符合”“支持”“基本验证”“未能验证”；不使用绝对化表述。

### 必选 B：主要误差或偏差

- 优先讨论能解释主要方向或量级的 1–3 项，不按“仪器—环境—人为”凑数量。
- 每项至少说明“误差源如何进入公式或装置，以及会影响哪个结果”。能判断方向时写方向；不能判断时如实说明。
- 原因未被复测证实时写“可能”“提示”或“不能排除”，不写成已经查明。

### 默认 C：思考与改进

- 每条改进对应前述某个问题，写清控制量、复测方式或判别标准。
- 优先提出能区分竞争解释的复测，而不仅是“多测几次”“认真操作”。
- 用户要求思考题但材料中没有教师原题时，可写“思考与改进”，采用陈述语气；不得冒充教师布置的思考题。
- 若用户只要结果结论、报告纸没有该栏，且现有证据无法提出有针对性的改进，可以省略，不用通用套话补齐。

### 条件选用

- **趋势与机理**：存在清楚趋势或拟合关系时使用，并写适用范围。
- **异常点分析**：只有局部偏离时，比较异常点与其余点的方向、绝对差和相对差。
- **重复性与准确度**：重复读数稳定但与参考值有偏差时使用，明确二者不等价。
- **方法比较**：存在两种方法或理论/实验比较时使用，先核查独立性。
- **实验反思**：用户或课程明确要求时使用；写本实验暴露的方法问题，不写泛泛感想。

## 5. 证据链写法

一个完整论点通常包含四步，正文可压缩成一两句：

> 结果或观察 → 与模型/参考/其余数据比较 → 解释及证据强度 → 结论边界或改进

例如：

> “低量程组的相对偏差明显大于其余组，而绝对差并未同比例增加，说明小基数放大了相对偏差；应优先复测基线量和低量程点，以区分基线偏移与单点操作误差。”

这类句子优于“存在人为误差，应认真测量”，因为它同时说明了证据、机制和下一步。

## 6. 误差分析的科学门槛

先在处理记录中用下表筛选原因；正文只保留通过筛选的高价值项。

| 项 | 问题 |
|---|---|
| 误差源 | 它具体是哪个量、部件、条件或假设？ |
| 传播路径 | 它通过哪条公式或物理过程影响结果？ |
| 预期方向 | 会使结果偏高、偏低，还是方向不定？ |
| 量级一致性 | 读数末位足以解释偏差，还是需要远超分辨率的变化？ |
| 数据一致性 | 它能解释全部组、某一组或某一方向的现象吗？ |
| 判别办法 | 怎样复测、对照或改变条件可以验证？ |

使用以下约束：

- 百分差大不等于不确定度大；百分差小也不能证明无系统偏差。
- 重复测量接近只说明重复性较好，不能单独证明准确度。
- 已观察到的装置异常可以写为事实，但其对结果的影响仍需作为假设，除非有对照证据。
- 当若干原因都可能成立而数据不能区分时，明确“现有数据不足以确定主因”，并提出判别复测。
- 对单点异常，先查转录、单位、公式、工况和操作记录，再讨论删点；不得因结果不好而静默剔除。
- 若量级估算显示某个读数末位不足以解释偏差，应据此降低该原因的优先级，而不是继续把它列为主因。

## 7. 可直接复用的正文骨架

方括号是写作提示，不能原样留在交付稿中。

### 精简版（通常足够）

1. **实验结果与结论。** [核心结果]；与[理论/参考/关系]比较，[支持程度与范围]。[主要例外，如有]。
2. **误差分析。** [主要偏差或异常]集中在[对象/范围]。[原因 1]可能通过[路径]使[结果方向]；[原因 2]只能解释[局部或方向]，现有数据[能/不能]区分。
3. **思考与改进。** 应[具体控制或复测]，并以[判别量]比较改进前后结果；这可以检验[原因]并减小[对应影响]。

### 扩展版（存在趋势、异常或多方法比较时）

1. **主要结果**：最终值、关系及结论边界。
2. **趋势或方法比较**：首末值/斜率/残差/吻合度，以及是否独立。
3. **异常与误差**：最突出偏离、传播路径、方向与证据强度。
4. **重复性或模型限制**：只在确有数据时写。
5. **思考与改进**：一项控制实验、一项操作或装置改进；均与前文问题对应。

段落标题可按报告纸改成“实验结论—误差分析—思考与改进”，也可合并为“结果讨论与分析”。结构服从用户模板，不因参考文档固定标题。

## 8. 篇幅与交付层次

- **正文**默认用 3–5 个短段、约 250–500 个汉字；单一结果可更短，多组独立结果可适当增加。本条只管正文篇幅，不限制处理说明（处理说明尽量不省略）。完整性由证据链决定，不以凑字数为目标。
- 报告正文优先给结论、关键证据和高价值原因；详细反事实计算、识别争议和替换记录留在说明。
- 用户同时需要报告内容和说明时，先给“可写入报告的正文”，紧接“说明与溯源”；除非用户要求，不拆成两份文件或另起页。
- 说明可列数字来源、口径选择、数据替换、未采用原因、参考报告差异和教师批注裁决；这些内容不能混入正文语气。

## 9. 交付前检查

- [ ] 开头是否明确回答“实验得到什么、支持什么结论”？
- [ ] 每项关键结论是否有本次数字或明确观察支撑？
- [ ] 是否区分结果、重复性、不确定度和相对偏差？
- [ ] 是否区分观察事实、物理推断和未证原因？
- [ ] 误差原因是否写出传播路径，并与方向或量级相容？
- [ ] 改进是否对应具体原因，并给出可执行的验证方法？
- [ ] 是否避免循环验证、只看相关系数、按结果挑数据和通用套话？
- [ ] 正文是否未夹入数据修订过程、往届对照或内部诊断说明？
- [ ] 若有教师原题，是否逐题作答；若无，是否明确写成“思考与改进”？
- [ ] 数字、单位、修约、表号和图号是否与最终报告一致？
